# Sentinel-2 Spectral Index Computation

A Python script for computing spectral indices from Sentinel-2 Level-2A GeoTIFF band mosaics produced by `median_composite.py`. Supports chunk-based raster processing, configurable index parameters, output compression, nodata handling, and a progress bar with elapsed time and estimated time remaining.

## Features

- Computes six spectral indices: NDVI, NDWI, MNDVI, MNDWI, SAVI, and SABI.
- Enables or disables individual indices through the `COMPUTE` configuration.
- Reads only the input bands required by the enabled indices.
- Processes large rasters in configurable row chunks to manage memory usage.
- Displays a progress bar with completion percentage, chunks processed, elapsed time, and estimated time remaining.
- Supports configurable MNDVI scaling constants and SAVI/SABI soil-brightness parameters.
- Optionally clamps index values to the range [-1, 1].
- Handles no-data pixels using NaN values.
- Supports LZW and DEFLATE compression, or uncompressed output.
- Skips existing outputs unless `OVERWRITE` is enabled.

## Requirements

- Python 3.9 or later
- NumPy
- Rasterio
- Input Sentinel-2 band mosaics generated by `median_composite.py`

Install dependencies:

```bash
pip install numpy rasterio
```

## Configuration

Open `compute_spectral_indices.py` and configure the following parameters.

| Parameter | Description |
|---|---|
| `BAND_PATHS` | File paths to the input Sentinel-2 band GeoTIFFs |
| `OUT_DIR` | Directory where computed index rasters will be saved |
| `COMPUTE` | Enables or disables each spectral index |
| `MNDVI_C1` | Numerator scaling constant for MNDVI |
| `MNDVI_C2` | Denominator scaling constant for MNDVI |
| `SAVI_L` | Soil-brightness correction factor for SAVI |
| `SABI_L` | Soil-brightness correction factor for SABI |
| `CHUNK_ROWS` | Number of raster rows processed per chunk |
| `NODATA_OUT` | Output no-data value |
| `CLAMP` | Enables or disables output clamping to [-1, 1] |
| `COMPRESS` | Output GeoTIFF compression: `lzw`, `deflate`, or `none` |
| `OVERWRITE` | Determines whether existing output files are replaced |

### Input bands

Configure `BAND_PATHS` to point to the corresponding mosaics:

| Band | Description |
|---|---|
| B02 | Blue |
| B03 | Green |
| B04 | Red |
| B08 | Near-infrared (NIR) |
| B11 | Shortwave infrared (SWIR) |

All required input rasters must have matching dimensions, coordinate reference systems, and pixel alignment. The script uses the first opened band's profile as the reference for the outputs.

### Enabling indices

Set each index to `True` or `False` in `COMPUTE`:

```python
COMPUTE = {
    "NDVI":  True,
    "NDWI":  True,
    "MNDVI": True,
    "MNDWI": True,
    "SAVI":  True,
    "SABI":  True,
}
```

Only enabled indices are calculated. The script opens only the input bands required by those indices.

## Usage

After updating the input and output paths, run:

```bash
python compute_spectral_indices.py
```

The script opens the necessary band rasters, creates output GeoTIFFs, and processes the input images in row chunks. A progress bar updates as each chunk is completed.

## Spectral Index Formulas

| Index | Formula | Primary application |
|---|---|---|
| NDVI | `(NIR - Red) / (NIR + Red)` | Vegetation greenness |
| NDWI | `(Green - NIR) / (Green + NIR)` | Water-related feature detection |
| MNDVI | `C1 × (NIR - Red) / [C2 × (NIR + Red)]` | Configurable normalized vegetation index |
| MNDWI | `(Green - SWIR) / (Green + SWIR)` | Open-water and built-up feature analysis |
| SAVI | `[(NIR - Red) / (NIR + Red + L)] × (1 + L)` | Vegetation analysis with soil-brightness adjustment |
| SABI | `[(SWIR - NIR) / (SWIR + NIR + L)] × (1 + L)` | SWIR–NIR spectral contrast using the configured correction factor |

The exact interpretation of each index depends on its formula, input bands, and application context. In particular, the names MNDVI and SABI can refer to different formulations across publications; the formulas implemented in this script define the outputs produced.

## Output Structure

```text
OUTPUT_DIRECTORY/
├── NDVI.tif
├── NDWI.tif
├── MNDVI.tif
├── MNDWI.tif
├── SAVI.tif
└── SABI.tif
```

Only enabled indices that are not skipped because of existing output files are generated.

Each output is a single-band, float32 GeoTIFF using the reference raster's dimensions, georeferencing, and coordinate reference system.

## Processing Workflow

1. Reads the enabled-index configuration.
2. Identifies and opens the required input bands.
3. Creates output GeoTIFFs using the reference raster profile.
4. Reads the rasters in configurable row chunks.
5. Computes the selected spectral indices.
6. Applies optional clamping and propagates NaN values from required input bands.
7. Writes each chunk to the corresponding output raster.
8. Closes the datasets and reports the final output file sizes.

## Notes

- `CHUNK_ROWS` can be reduced if available RAM is limited.
- The progress bar tracks completed chunks rather than individual index calculations.
- The script treats input values equal to zero as no-data. This is appropriate only when zero represents missing data in the input rasters; valid zero-valued reflectance pixels would also be masked.
- `CLAMP=True` restricts outputs to [-1, 1]. This can affect indices such as SAVI or SABI whose configured formulas may produce values outside that range.
- `NODATA_OUT=float("nan")` writes NaN as the output no-data value.
- Input band scaling must be consistent with the formulas and configured constants. Normalized ratios are generally invariant to common multiplicative scaling, but SAVI and SABI include additive correction factors, so their results depend on the reflectance scale.
- The script computes spectral indices only; it does not download imagery, stitch tiles, or train a machine-learning model.
